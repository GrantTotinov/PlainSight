**Title** (75 max): PlainSight : masquer les Aperçus IA et le Mode IA dans la recherche Google™

**Short description** (132 max): Retire les Aperçus IA et le Mode IA de la recherche Google. Retrouvez les résultats classiques. Gratuit, open source, sans pistage.

**Full description:**

Retrouvez vos résultats de recherche, sans résumé IA en haut de la page.

PlainSight retire les Aperçus IA et les boutons du Mode IA de la recherche Google. La première chose que vous voyez redevient une liste de vrais sites web.

CE QUE VOUS OBTENEZ
• Une page de résultats nette. Le résumé IA est masqué avant d'apparaître, rien ne saute à l'écran.
• Plus d'onglets ni de boutons du Mode IA sur la page de résultats ou la page d'accueil.
• En option : ouvrir le Mode IA vous renvoie vers les résultats classiques.
• Mode « Web uniquement » : chaque recherche s'ouvre dans le filtre Web de Google. Des liens, rien d'autre, et cela continue de fonctionner quand Google modifie sa page.
• Mettez en pause sur un onglet en un clic quand vous voulez la page complète.

COMMENT ÇA MARCHE
Choisissez un mode à l'installation. « Masquer l'IA » garde la page de résultats habituelle et retire les parties IA. « Web uniquement » passe vos recherches au filtre Web intégré, l'option la plus fiable car elle ne dépend pas de la mise en page. Changez de mode ou désactivez PlainSight à tout moment depuis le bouton de la barre d'outils.

CONFIDENTIALITÉ
PlainSight ne collecte aucune donnée. Pas d'analyse, pas de pistage, pas de code distant, aucune requête réseau de sa part. Vos réglages restent dans votre navigateur. Le code est open source sur GitHub, chacun peut le vérifier.

Fonctionne sur tous les domaines Google, dans toutes les langues.
